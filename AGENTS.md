# AGENTS.md

Инструкции для любых AI-агентов (Claude Code, Codex, Cursor, Copilot и т.д.), которые пишут код в этом репозитории.

## Код-стайл — обязателен

Перед тем как писать код, прочитай [CODE_STYLE.md](CODE_STYLE.md) и следуй ему. Это не рекомендации, а правила проекта:
механические части проверяются `golangci-lint` (конфиг — [.golangci.yml](.golangci.yml)), остальное — на ревью.

Ключевое, что чаще всего нарушают:

- Ошибки оборачиваются с контекстом: `fmt.Errorf("failed to <действие>: %w", err)`; сравнение — только `errors.Is` / `errors.As`.
- Импорты — три группы: stdlib → внешние → `github.com/Prokud1n/ai-agents/...`.
- Не мутируем входные слайсы в циклах: копия элемента → новый слайс.
- Никаких магических чисел (кроме 0–3), `init()`, `interface{}` (используем `any`), `FIXME`.
- Функция — не более 50 statements и сложность ≤ 15.
- `//nolint` — только в виде `//nolint:<linter> // <причина>`.
- Интерфейсы объявляет потребитель; зависимости — через Uber FX (`Module` в `fx.go` каждого пакета).
- Табличные тесты с `t.Parallel()` и `testify`.

## Команды

```bash
make setup   # один раз после клонирования: включает git-хуки
make fmt     # отформатировать код
make lint    # golangci-lint
make test    # go test ./...
make check   # lint + test — то же, что проверяет pre-commit и CI
```

## Перед тем как закончить задачу

1. `make fmt` и `make check` проходят без ошибок.
2. Новая бизнес-логика покрыта тестами.
3. Если изменение заметно пользователю — добавлена запись в `CHANGELOG.md` (раздел `[Unreleased]`).

## Запрещено

- Коммитить с `--no-verify` или иначе обходить pre-commit хук.
- Ослаблять `.golangci.yml` или добавлять `//nolint`, чтобы «пройти» линтер, — вместо этого исправь код. Если правило действительно мешает — спроси человека.
- Редактировать уже смерженные миграции.
- Коммитить `.env` и секреты.
