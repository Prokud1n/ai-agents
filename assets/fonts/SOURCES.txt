Subtitle fonts (SUBTITLES_FONTS_DIR). Both are licensed under the SIL Open Font License 1.1:
the license texts are next to the fonts and must stay with them.
libass matches a static font by its legacy family name, which includes the weight for weights other than
Regular/Bold: the style names them "Manrope Medium" and "Fira Sans Extra Condensed ExtraBold".

  The repository ships only the variable font, and libass 0.17 does not select named instances of a
  variable font loaded from fontsdir (it silently falls back to a system font). So the static Medium
  instance is cut from it with fontTools 4.60.1:
    fonttools varLib.instancer --static --update-name-table -o Manrope-Medium.ttf "Manrope[wght].ttf" wght=500
  The OFL text of Manrope names no Reserved Font Name, so the instance keeps the name "Manrope".
  Result: sha256 f7c3def2dcebca8d8a210e654fd32dd41f8237a5da4d6d96394eb9cfad055923
  (the instancer writes a timestamp, so a rebuild differs in bytes but not in glyphs).
